## 📂 Step-by-Step Guide

### **Method 1: Drag & Drop (Easiest)**
1. Open your project folder in Finder
2. Navigate to `public/images/hero/`
3. Drag and drop both images into this folder
4. Rename them:
   - First image → `orbit-kids-laptop.jpg`
   - Second image → `orbit-kids-banner.jpg`
5. Commit and push:
   ```bash
   git add public/images/hero/
   git commit -m "Add Orbit brand hero images"
   git push origin main
   ```

### **Method 2: Command Line**
1. Save your images to Downloads or Desktop
2. Run these commands:
   ```bash
   cd "/Users/macbookair/Downloads/project 129"
   cp ~/Downloads/orbit-kids-laptop.jpg public/images/hero/
   cp ~/Downloads/orbit-kids-banner.jpg public/images/hero/
   git add public/images/hero/
   git commit -m "Add Orbit brand hero images"
   git push origin main
   ```
